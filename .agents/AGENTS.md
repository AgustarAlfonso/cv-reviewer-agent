# Project Rules: CVSight

The following rules must be strictly adhered to during the development of this project:

1. **Docstrings Required**: Every new module, class, method, and function created or modified must have clear and descriptive docstrings. For Python, use standard PEP 257 format. For JavaScript/React, use JSDoc format.
2. **Documentation Updates**: For every significant addition or change to the project, a corresponding markdown document MUST be created or updated in the `docs/` folder to document the new feature, architecture change, or API addition.
